Lesson 6: Interpreting music in context

Lesson 6 of 50 · Listening, analysing and responding

Learning intention

Explain how context influences the way a work is interpreted, compare two versions of the same work and account for the differences, and investigate how performance conventions carry stylistic identity.

By the end you can: Compare two versions of a work, name what changed, and explain how context accounts for the difference, with musical evidence.

Outcomes MU1-11L-01 MU1-11L-02

Success criteria

Tick them off as you go.

In classThis fortnight

  1. Compare an original recording with a later cover of the same song, using the original-versus-cover frame.
  2. Investigate performance conventions across two traditions and note how their conventions reflect distinct contexts.
  3. Week 9: write a short, evidence-based paragraph analysing how context shapes meaning in one chosen work, using identify, describe, explain.
  4. Support each point in your paragraph with a specific musical example.
