How the session runs

Independent research is defended the same way class analysis is: an observation is only useful if it can be backed with a specific musical feature, named and located in the repertoire. This is a working session with a teacher conference for each student, not a free research period.

In class this fortnight

  • 01Research the composer, sub-genre or tradition confirmed in Week 2, using reliable sources.
  • 02Identify specific musical features of its repertoire and compare them against the term’s taught core (leitmotif, notation, scoring technology, cultural tradition).
  • 03Draft interpretative observations, each backed by a named musical feature, ready for the teacher conference.
  • 04Teacher conference: check that each observation is defensible with evidence, not only asserted.
